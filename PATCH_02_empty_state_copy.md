# Empty-state copy recommendations

Use these labels/messages when a section has no data.

## Command Center / Top Root Causes
**Title:** No recurring causes detected

**Body:** No recurring failure clusters were detected in the selected time window.

## Fix Queue
**Title:** No active incidents

**Body:** We did not detect active incident clusters right now. Refresh data or review readiness risks for early warnings.

## Reports
**Title:** No report data available

**Body:** Connect a tenant and refresh data to generate compliance and enrollment insights.

## OCR
**Title:** Start with an image or pasted error text

**Body:** Upload a screenshot or paste raw error text to generate an explanation and remediation guidance.
